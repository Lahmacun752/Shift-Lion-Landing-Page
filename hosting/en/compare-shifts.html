Understand the result

What does this tool calculate?

The tool overlays two repeating shift rotations and identifies dates when both people are off.

Example

Two eight-day rotations can begin on different dates; the tool aligns both sequences and marks only genuine shared days off.

How it is calculated

For each date, the tool calculates the position in each rotation. A match occurs only when both positions are set to “Off”.

What is not included?

Last-minute roster changes, leave, sickness and appointments are not included automatically.

Frequently asked questions

Must both rotations have the same length?

No. Each person can use a different rotation length.

Why does the start date matter?

It defines the calendar date on which day 1 of each rotation begins.

Can I compare more than two people?

The web tool compares two people; the Shift Lion app supports additional groups.
