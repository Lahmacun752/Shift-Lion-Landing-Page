Shift planning guide

Find shared days off in shift schedules

When two people work different rotations, shared weekends are not guaranteed. Correct start dates and complete sequences make shared days off predictable.

Compare shifts now →

Information you need

  • For each person, a date known to be day 1
  • The complete sequence of early, late, night and off days
  • The month or period to compare

How comparison works

  • Every calendar date is assigned a position in each rotation.
  • After the final rotation day, the sequence begins again.
  • A shared day off occurs only when both positions are marked Off.

Example with shifted rotations

  • Person A starts an eight-day rotation on the first day of the month.
  • Person B starts another rotation on the third.
  • The calculator accounts for the offset and displays matches in a list and calendar.

Using the result

  • Plan appointments, trips or family time early.
  • Update the start date if a rotation changes permanently.
  • Handle short-notice swaps and leave separately.

FAQ

Questions about this topic

Must both rotations have the same length?

No. Rotations of different lengths can be compared.

What does the start date mean?

It is the calendar date on which day 1 of that person's rotation begins.

Can I include leave?

The simple web comparison uses the base rotation; personal events and leave are better managed in the app.
